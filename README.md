# Soliq — mobil frontend (UI nusxa)

Soliq ilovasi interfeysining toza HTML/CSS/JS nusxasi. Norasmiy, demo loyiha. Server kerak emas — `index.html` ni brauzerda oching.

| Sahifa | Fayl |
|---|---|
| Bosh sahifa | `index.html` |
| Xizmatlar | `xizmatlar.html?tab=soliqlarim` |
| Ota-onam soliqlarini to'lash | `ota-onam.html` |
| MIB qarzlari | `mib.html` |

Stil va skriptlar: `assets/`.
